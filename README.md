# Pa'O Dictionary & Audio Dataset (ပအိုဝ်းအဘိဓာန် နှင့် အသံဒေတာ)

[![Open Source](https://badges.frapsoft.com/os/v1/open-source.svg?v=103)](https://opensource.org/)

## 📖 About The Project (ပရောဂျက်အကြောင်း)

**English:**
This repository is an open-source Pa'O Dictionary and Audio Dataset. It contains Pa'O words, phrases, and authentic audio pronunciations aimed at preserving the language and providing resources for developers, researchers, and AI (NLP/Speech-to-Text) enthusiasts. 

**မြန်မာ (Myanmar):**
ဤ Repository သည် လွတ်လပ်စွာရယူအသုံးပြုနိုင်သော (Open-source) ပအိုဝ်းအဘိဓာန်နှင့် အသံဒေတာစုစည်းမှု ဖြစ်ပါသည်။ ပအိုဝ်းဘာသာစကားကို ထိန်းသိမ်းရန်နှင့် နည်းပညာနယ်ပယ် (AI, NLP, Speech-to-Text) တွင် အသုံးပြုလိုသော Developer များ၊ သုတေသီများအတွက် ရည်ရွယ်၍ ပအိုဝ်းစကားလုံးများ၊ စကားစုများနှင့် အသံထွက်ဖိုင်များကို စုဆောင်းမျှဝေထားခြင်း ဖြစ်ပါသည်။

## ✨ Features (ပါဝင်သော အချက်အလက်များ)

- **Vocabulary & Phrases:** A comprehensive list of Pa'O words and daily conversational phrases. 
  (ပအိုဝ်း စကားလုံးများနှင့် နေ့စဉ်သုံး စကားစုများ)
- **Audio Files:** Voice recordings for accurate pronunciation. 
  (တိကျမှန်ကန်သော အသံထွက်များအတွက် အသံဖိုင်များ)
- **Open-source:** Free to use for language learning, mobile apps, and machine learning models. 
  (ဘာသာစကားလေ့လာရန်၊ App များရေးသားရန်နှင့် AI Model များအတွက် အခမဲ့ ရယူအသုံးပြုနိုင်ခြင်း)
